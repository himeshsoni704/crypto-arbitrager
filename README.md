# crypto-arbitrager

## Description
A TypeScript tool that detects and simulates triangular arbitrage opportunities across crypto exchanges.

## Features
- Real-time monitoring of exchange rates
- Identifies profitable arbitrage opportunities
- Logs results for analysis

## Tech Stack
- TypeScript
- Node.js
- Websockets / Exchange APIs

## How to Run
1. Clone the repo  
2. Install dependencies: `npm install`  
3. Add API keys in `config.json`  
4. Run: `npm start`

## Future Improvements
- Automated trading execution  
- Multi-exchange support
